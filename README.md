# 🚀 Space Shooter Game

A fun, fast-paced space shooter game built with HTML5 Canvas and vanilla JavaScript!

## 🎮 How to Play

- **Arrow Keys** or **WASD** to move your ship
- **SPACEBAR** to shoot
- Destroy enemy ships to earn points
- Avoid enemy fire and collisions
- Survive waves of enemies to progress to higher levels

## 🎯 Game Features

- 🌟 Progressive difficulty with levels and waves
- 💥 Explosive particle effects
- 🎨 Neon retro-style graphics with glow effects
- 💪 Strong enemies that take 2 hits to destroy
- 🔄 Procedurally spawned enemy waves
- 📊 Score and lives tracking
- 🎵 Smooth animations and visual feedback

## 📋 Scoring

- **Basic Enemy**: 10 points
- **Strong Enemy**: 20 points (takes 2 hits)
- **Lives**: Start with 3 lives

## 🚀 Getting Started

1. Open `index.html` in your web browser
2. Start shooting and have fun!

## 🛠️ Technical Details

- **Canvas-based rendering** for smooth performance
- **Object-oriented design** with class-based entities
- **Collision detection** for bullets, enemies, and player
- **Particle system** for visual effects
- **Keyboard input handling** with support for multiple control schemes

Enjoy! 🎉
